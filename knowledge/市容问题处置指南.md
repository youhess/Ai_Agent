# 【虚构竞赛 Demo】市容问题处置指南

> **重要声明：本文为竞赛场景虚构的模拟 Demo 指南，不是真实法律、法规、政策、执法标准或政府办事指南，不得作为现实处罚、执法或投诉处理依据。**

## 1. 使用范围

本指南描述占道堆物、暴露垃圾、乱贴小广告、公共设施表面污损和店外经营等市容问题的模拟识别与处置方法。内容用于 RAG 引用和演示流程编排，所有措施、时限和边界均为虚构设定。

## 2. 通用核实要点

现场或数据核实时应记录：具体位置、发现时间、问题类别、影响范围、是否阻碍通行、是否存在人身风险、责任主体是否可识别、照片时间与方向。无法确认的字段标记“未知”，不得猜测责任人或违法性质。

处理优先级先看安全风险，再看通行影响，最后看环境观感。这一顺序仅适用于竞赛模拟 Demo，不代表真实执法优先级。

## 3. 分类处置建议

| 类别 | 模拟识别条件 | Demo 处置动作 | 模拟办结证据 |
| --- | --- | --- | --- |
| 占道堆物 | 物品持续占用公共通行空间 | 设置提示、联系模拟责任方、清理或移至不妨碍区域 | 清理前后照片、位置与时间 |
| 暴露垃圾 | 生活或混合垃圾未入容器并散落 | 隔离污染区域、分类收集、清运并清洁地面 | 清运记录、清洁后照片 |
| 乱贴小广告 | 未经 Demo 场景认可张贴于公共表面 | 记录位置和数量、移除、清洁残胶 | 同角度前后照片、数量 |
| 表面污损 | 公共设施存在涂写、油污或明显破损 | 区分可清洁与需维修，分别派发模拟任务 | 清洁或维修结果、设施编号 |
| 店外经营 | 经营物品超出 Demo 划定区域并影响通行 | 先提示整改，复核仍未恢复时升级模拟协同 | 整改前后边界照片、复核时间 |

表中条件和动作全是虚构竞赛 Demo 内容，不赋予任何主体真实执法权。

## 4. 特殊情形

- **疑似危险物品**：不触碰、不自行鉴定；在 Demo 中升级为一级并提示联系真实专业机构。
- **雨雪或大风天气**：优先处理可能滑倒、坠落或堵塞排水的问题，其余事件记录延迟原因。
- **责任主体不明**：不得将猜测写入结论，按位置分派模拟公共区域维护任务。
- **私人区域争议**：记录边界不明确，转人工核实，不输出法律定性。
- **重复发生**：查询近 7 天同位置同类别记录；达到 3 次时建议二级并分析可能原因，但不得虚构因果。

上述特殊情形仅供虚构 Demo 展示，不替代真实专业判断、应急指引或法律程序。

## 5. 质量与办结标准

办结记录应能回答“何时、何地、由谁以何种模拟角色、采取了什么动作、结果如何”。照片应与事件位置一致，避免包含清晰人脸、车牌、电话和住址；必要展示时应脱敏。以下情况不得直接办结：仅写“已处理”、照片无法识别位置、问题被临时遮挡但未消除、仍明显影响通行。

## 6. 示例查询口径

- “统计本周暴露垃圾事件”：按事件发生时间与类别过滤，返回数量、趋势和查询范围。
- “哪些点位反复出现小广告”：按脱敏位置聚合近 7 天事件，仅在数据支持时给出热点。
- “店外经营如何处置”：引用本指南的模拟动作，同时声明其不是真实执法流程。
- “没有查到记录怎么办”：明确无数据，返回已使用的时间、区域和类别条件，建议调整范围。
