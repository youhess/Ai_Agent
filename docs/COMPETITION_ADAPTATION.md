# 竞赛场景一小时适配指南

本文面向已有城市治理智能体 Demo 的现场换题适配。目标是在 60 分钟内替换场景语义和演示数据，同时保持调用链、接口契约和安全边界稳定；不在现场重构系统。

## 一小时节奏

| 时间 | 工作项 | 验收结果 |
| --- | --- | --- |
| 0-5 分钟 | 阅读赛题，提取对象、指标、时空范围、风险词 | 一页字段映射和演示主线 |
| 5-15 分钟 | 修改配置和样例数据 | 新场景可筛选、可聚合且有空结果 |
| 15-25 分钟 | 适配工具描述、参数枚举和 Schema | 工具调用参数合法，返回结构稳定 |
| 25-35 分钟 | 调整仪表盘标签、指标与默认筛选 | 首屏与赛题一致，无旧场景残词 |
| 35-45 分钟 | 替换知识材料与提示词 | RAG 可引用，回答有来源与边界 |
| 45-55 分钟 | 跑核心评测和完整演示链路 | 查询、分析、RAG、多工具、无数据、安全均通过 |
| 55-60 分钟 | 冻结版本并准备降级演示 | 记录配置快照、已知限制和备用提问 |

## 先做字段映射

先把赛题名词映射到现有稳定概念，避免改动底层架构：

| 稳定概念 | 需要替换的场景内容 | 不应改变 |
| --- | --- | --- |
| event | 事件名称、类别、状态 | 主键语义、时间字段类型 |
| region | 街道、园区、社区或网格 | 层级查询方式 |
| severity | 赛题等级名称与解释 | 可排序、可过滤的约束 |
| metric | 指标名称、单位、计算口径 | 聚合结果结构 |
| knowledge | 新赛题的模拟规范与指南 | 检索引用和来源展示机制 |

## 分项适配步骤

### 1. 配置

- 改：场景标题、类别枚举、等级标签、默认时间范围、功能开关、展示单位。
- 查：环境变量是否齐全，模型、数据源和知识库连接是否可用。
- 不改：密钥管理方式、认证策略、部署拓扑和全局错误处理。
- 验收：启动时无未知枚举；页面、工具和提示词使用同一套配置值。

### 2. 数据

- 改：准备 20-50 条小而完整的演示数据，覆盖不同区域、时间、类别、状态和等级。
- 必备：至少一组趋势数据、一组重复点位、一条跨类别关联、一条处理中事件、一个明确空结果条件。
- 处理：使用虚构或脱敏数据；统一时区、日期格式、单位和缺失值表示。
- 不改：核心 ID 类型、分页协议和数据访问层接口。
- 验收：总量可人工核算；筛选后结果与预设答案一致；无数据时不生成虚假记录。

### 3. 工具

- 改：工具名称的展示文案、描述、适用条件、参数说明和类别枚举，使模型知道“何时调用哪个工具”。
- 保持：查询工具只读，分析工具基于查询结果，知识检索不冒充实时数据。
- 不改：已稳定的超时、重试、鉴权、日志和错误返回机制。
- 验收：单工具问题不会多调用；综合问题能先查数据再分析；危险或越权请求不调用执行型工具。

### 4. Schema

- 改：枚举值、字段描述、示例值及必要/可选标记。
- 对齐：请求 Schema、工具实现、响应 Schema、前端消费字段和提示词中的字段名必须一致。
- 不改：无明确必要时不要新增嵌套层级、修改公共字段类型或破坏现有调用契约。
- 验收：合法样例通过校验；非法类别、反向时间范围和缺失必填字段得到明确错误。

### 5. 仪表盘

- 改：标题、指标卡、图例、筛选项、地图或表格字段、空状态文案。
- 推荐首屏：总量、办结率或场景核心率、趋势、类别分布、区域排行、待关注列表。
- 不改：成熟的响应式布局、图表基础组件和加载/错误状态。
- 验收：数值与工具查询一致；单位和时间口径可见；移动端不截断关键结论。

### 6. 知识库

- 改：替换为赛题相关的短文档，每篇聚焦一个主题，使用清晰标题、条件、例外、表格和检索关键词。
- 必须：虚构材料反复声明“竞赛模拟 Demo，非真实法规政策”；真实材料则保留来源、发布日期和有效范围，二者不可混用。
- 检查：分块后标题与免责声明仍在上下文中；同义词能命中；引用可追溯到文件名。
- 不改：现场无充分依据时不要伪造法律条文、文号、机构职责或真实政策结论。
- 验收：典型问题命中正确文档；无依据的问题明确表示未检索到，而不是编造答案。

### 7. 提示词

- 改：角色描述、领域词汇、工具选择规则、输出模板、赛题限制和免责声明。
- 加：先澄清时间/区域、数据事实必须来自工具、知识结论必须带来源、无数据不得推断、敏感信息需脱敏。
- 不改：防提示注入、权限边界、事实与建议分离、拒绝危险请求等通用安全规则。
- 验收：同一问题重复测试时，意图和工具选择稳定；答案明确区分数据结果、知识依据和模型建议。

## 不要现场改动

- 不重写后端框架、前端路由、认证、数据库迁移或部署脚本。
- 不为了一个演示问题增加不可复用的特殊分支。
- 不把固定答案写进提示词，不伪造工具调用和引用。
- 不接入未经检查的真实个人数据，不展示姓名、电话、门牌或精确轨迹。
- 不用 Demo 知识冒充法律、政策或专业处置意见。

## 10 分钟最小验收集

1. 数据查询：指定时间、区域、类别，数字与手工基准一致。
2. 综合分析：查询后给出趋势、异常和基于证据的建议。
3. RAG：回答规则问题，显示文件来源和 Demo 免责声明。
4. 多工具：先聚合发现热点，再查询明细并检索处置知识。
5. 无数据：明确查询范围和零结果，不杜撰原因。
6. 安全：拒绝泄露个人信息、伪造政策或执行越权操作。

## 交付清单

- 场景字段映射、配置快照和样例数据口径。
- 工具与 Schema 对齐记录。
- 仪表盘截图或现场检查结果。
- 知识文件清单、来源属性和免责声明检查。
- 提示词版本、核心评测结果、已知限制及降级演示问题。
